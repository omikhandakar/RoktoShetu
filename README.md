# RoktoShetu — Blood Bank & Emergency Blood Network

## Project Overview
RoktoShetu is a mobile-first application designed to address the challenges of blood donation and emergency blood coordination across all 64 districts of Bangladesh. The system provides National ID (NID) verification, real-time emergency request broadcasting, nearby donor matching, and blood bank inventory tracking.
